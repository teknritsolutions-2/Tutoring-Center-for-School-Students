# Fieldnote Learning Centre

A complete static tutoring-centre website for students in Grades 6–12.

## Run locally

Open `pages/index.html` directly in a browser. For consistent local testing, serve the project folder with any simple static file server and visit `/pages/index.html`.

There is no build step, package manager, backend, database, plugin runtime, or external authentication.

## Technology

- HTML5
- CSS3
- Vanilla JavaScript ES6+
- Locally downloaded fonts and photography

## Browser behavior

- Login fields begin empty. Valid front-end input routes to `dashboard.html`.
- Registration and contact forms are handled only in the browser.
- Student material buttons generate downloadable text resources locally.
- Light/dark theme and LTR/RTL preferences persist with browser local storage.

## Main entry point

`pages/index.html`

See `documentation/README.md` for the page inventory, responsive behavior, and customization notes.
