Learning format

A small batch with room to think aloud.

Programs combine explanation, guided work, independent practice, and individual correction.

01

Concept workshop

See the idea, connect representations, and ask the foundational question.

02

Problem studio

Compare methods and move gradually from prompts to independence.

03

Short home set

Practise the exact skill while the class explanation is still fresh.

04

Useful correction

Turn an error into a named pattern and one practical next action.

Exam & revision support

Revision begins before the final month.

Topic maps, mixed retrieval, timed sections, and correction cycles build exam readiness without replacing understanding.
